TYPICAL WORKFLOW
================
1. Development:
   npm run tauri dev

2. Make changes:
   - Frontend: src/components/*.tsx (hot reload)
   - Backend: src-tauri/src/*.rs (requires restart)

3. Test:
   ./test.sh

4. Build:
   ./build.sh

5. Install:
   sudo cp target/release/muthur-os-terminal /usr/local/bin/muthur
