# Survival Pack

Offline/local-only placeholder pack for future MUTHUR survival reference
content.

This package documents the intended folder structure for local survival notes,
checklists, map references, radio notes, power notes, medical boundaries, and
supporting docs. It does not implement runtime loading and is not wired into
core behavior.

## Scope

- Static placeholder data only.
- Terminal-safe and inspectable without GUI, AI, cloud, network, or Tauri.
- No external downloads or bundled third-party datasets.
- Future content should be reviewed against trusted public safety and local
  emergency-management sources before publication.

## Limitations

This pack is not medical, legal, tactical, rescue, or emergency-professional
advice. Do not rely on it during an emergency. The placeholder notes are general
educational headings for future work and intentionally avoid dangerous or
unverified instructions.

## Structure

- `wiki/` placeholder JSONL reference entries.
- `checklists/` placeholder checklist notes.
- `maps/` placeholder offline map notes.
- `radio/` placeholder communication notes.
- `power/` placeholder power planning notes.
- `medical/` placeholder medical-boundary notes.
- `docs/` placeholder documentation notes.
