A fullscreen cinematic terminal OS interface for Linux.

Real terminals. Live system data. Local AI. Full desktop replacement.
Inspired by the MU/TH/UR 6000 mainframe from Alien (1979) and eDEX-UI.

Install Features Usage Releases GitHub

CORE SYSTEMS

  • Multi-tab terminal emulator (xterm.js + PTY)
  • Real-time CPU, memory, network, disk monitoring
  • AI assistant with command auto-execution (Ollama)
  • 3D network globe with conflict/cyber/flight modes
  • Integrated file explorer
  • Built-in web browser
  • Battery monitoring for laptops

VISUAL INTERFACE

  • Fullscreen borderless window
  • CRT scanline and flicker effects
  • Matrix green color scheme (#00ff41)
  • Custom animated cursor with glow
  • Retro-futuristic sci-fi panel layout

PERFORMANCE

  • Startup: 1-2 seconds
  • Idle CPU: less than 10%
  • RAM: ~150 MB
  • Binary: ~18 MB (vs 200 MB for Electron apps)
  • Input latency: sub-10ms
