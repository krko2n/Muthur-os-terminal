# Application Icons

Place your application icons here:

- `32x32.png` - Small icon
- `128x128.png` - Standard icon
- `128x128@2x.png` - Retina display icon
- `icon.icns` - macOS icon
- `icon.ico` - Windows icon

You can generate these icons from a single source image using:

```bash
cargo install tauri-cli
cargo tauri icon path/to/source/icon.png
```

For now, you can use placeholder icons or generate them from any sci-fi themed image that fits the MUTHUR aesthetic.
